# Реализованные функции

## Основные функции (по ТЗ)

### 1. Загрузка JSON экспортов чатов
- **Описание:** Загрузка файлов экспорта истории Telegram чатов в формате JSON через WebApp
- **Тестирование:** Открыть WebApp, загрузить JSON файл экспорта из Telegram Desktop
- **Особенности:** Поддержка chunked upload для файлов любого размера (до 2 ГБ)

### 2. Извлечение участников чата
- **Описание:** Автоматическое извлечение списка участников из экспорта чата
- **Источник данных:** Поле `from_id` и `from` из сообщений (обычных и пересланных)
- **Тестирование:** Загрузить файл с чатом, проверить список участников в результате
- **Особенности:** Игнорируются удаленные аккаунты (по паттерну "deleted" в from_id), извлекаются участники из пересланных сообщений (игнорируются каналы)

### 3. Извлечение упоминаний
- **Описание:** Поиск и извлечение всех упоминаний @username из текста сообщений
- **Источник данных:** Текст сообщений (поиск паттерна @username)
- **Тестирование:** Загрузить файл с чатом, содержащим упоминания, проверить список в результате
- **Особенности:** Извлекаются только упоминания с валидным username, фильтруются дубликаты

### 4. Формирование Excel отчетов
- **Описание:** Автоматическое создание Excel файлов (.xlsx) с результатами анализа
- **Условие:** Создается для чатов с 50+ участниками
- **Структура:** Два листа - "Участники" (колонки: Имя-фамилия, ИД) и "Упоминания" (колонка: @username)
- **Тестирование:** Загрузить файл с чатом >=50 участников, получить Excel файл
- **Особенности:** Форматирование заголовков (синий фон, белый текст), автоширина колонок

### 5. Отправка результатов в Telegram
- **Описание:** Автоматическая отправка результатов обработки пользователю через Telegram Bot API
- **Формат:** Excel файл (>=50 участников) или текстовое сообщение (<50 участников)
- **Тестирование:** Загрузить файл, проверить получение результата в чате с ботом
- **Особенности:** Отправка с подписью (caption) содержащей статистику, автоматическая отправка кнопок для повторной загрузки

## Дополнительные функции

### 6. Chunked Upload (загрузка по частям)
- **Описание:** Разбиение больших файлов на части для надежной загрузки
- **Размер чанка:** 10 МБ
- **Максимум попыток:** 3 попытки на чанк с экспоненциальной задержкой
- **Тестирование:** Загрузить файл >50 МБ, проверить прогресс загрузки в интерфейсе
- **Особенности:** Автоматический retry при ошибках/таймаутах, отображение прогресса, таймаут 5 минут на чанк

### 7. Группировка файлов одного чата
- **Описание:** Автоматическое объединение нескольких файлов одного чата в один результат
- **Логика:** Группировка по `id` (приоритет) или `name`+`type` (если id нет)
- **Тестирование:** Загрузить несколько файлов одного чата, проверить объединение в один результат
- **Особенности:** Работает даже если `name` отличается или отсутствует, выбирается первое непустое имя из группы

### 8. Объединение результатов в один файл
- **Описание:** Опция для создания сводного отчета из всех загруженных файлов
- **Активация:** Чекбокс "Объединить результаты в один файл" (появляется при 2+ файлах)
- **Имя файла:** `combined-export-{YYYYMMDD_HHMMSS}.xlsx` (например: `combined-export-20251212_143025.xlsx`)
- **Тестирование:** Загрузить 2+ файла разных чатов, включить опцию, проверить один файл с объединенными данными
- **Особенности:** Все участники и упоминания из всех файлов объединяются в один список, дубликаты удаляются

### 9. Текстовый вывод для малых чатов
- **Описание:** Отправка результатов в виде текстового сообщения для чатов <50 участников
- **Формат:** Markdown с code блоками для удобного копирования
- **Структура:** Список участников и упоминаний в отдельных code блоках (тройные кавычки)
- **Тестирование:** Загрузить файл с чатом <50 участников, проверить текстовый вывод
- **Особенности:** Формат: `Имя (ID)` для участников, `@username` для упоминаний, без нумерации

### 10. Обработка различных кодировок
- **Описание:** Автоматическое определение и обработка файлов с разными кодировками
- **Библиотека:** chardet для определения кодировки
- **Fallback:** Попытка чтения с `errors="replace"` при ошибках UTF-8
- **Тестирование:** Загрузить файл не в UTF-8, проверить корректную обработку
- **Особенности:** Проверка уверенности определения (>90%), детальные сообщения об ошибках кодировки

### 11. WebApp интерфейс
- **Описание:** Веб-интерфейс для загрузки файлов внутри Telegram
- **Функции:** Drag & Drop, выбор нескольких файлов (до 10), прогресс загрузки, список выбранных файлов
- **Тестирование:** Открыть WebApp через бота, проверить интерфейс и загрузку
- **Особенности:** Адаптивный дизайн, поддержка мобильных устройств, отображение размера файлов, возможность удаления файлов из списка

### 12. Туннель Tuna для WebApp
- **Описание:** Настройка публичного HTTPS URL через туннель Tuna
- **Скрипт:** `tunnel_setup.sh` для автоматической настройки
- **Тестирование:** Запустить скрипт, проверить доступность WebApp по HTTPS
- **Особенности:** Автоматическое обновление BACKEND_URL в .env, запуск в Docker контейнере, сохранение токена в volume

### 13. Обработка ошибок
- **Описание:** Детальная обработка и сообщение об ошибках пользователю
- **Типы ошибок:** Неверный формат файла, проблемы с кодировкой, поврежденный JSON, отсутствие поля messages
- **Тестирование:** Загрузить некорректный файл, проверить понятное сообщение об ошибке
- **Особенности:** Валидация структуры JSON перед обработкой, проверка типа поля messages (должен быть список)

### 14. Автоматическая очистка файлов
- **Описание:** Удаление загруженных файлов сразу после обработки
- **Безопасность:** Файлы не сохраняются на сервере, удаляются после отправки результата
- **Тестирование:** Загрузить файл, проверить отсутствие файлов в папке uploads после обработки
- **Особенности:** Удаление как исходных файлов, так и временных чанков, обработка ошибок удаления

### 15. Обработка нескольких файлов одновременно
- **Описание:** Возможность загрузить до 10 файлов за один раз
- **Обработка:** Каждый файл обрабатывается отдельно, результаты группируются по чатам
- **Тестирование:** Загрузить 3-5 файлов одновременно, проверить обработку всех
- **Особенности:** Последовательная загрузка чанков, параллельная обработка после загрузки, отдельные результаты для каждого чата

### 16. Валидация структуры JSON
- **Описание:** Проверка корректности структуры экспорта Telegram перед обработкой
- **Проверки:** Наличие поля `messages`, тип данных (список), наличие обязательных полей
- **Тестирование:** Загрузить некорректный JSON, проверить сообщение об ошибке
- **Особенности:** Детальные сообщения об ошибках валидации, проверка типа данных

### 17. Игнорирование удаленных аккаунтов
- **Описание:** Автоматическое исключение удаленных аккаунтов из результатов
- **Определение:** По паттерну "deleted" в `from_id` (регистронезависимо)
- **Тестирование:** Загрузить файл с удаленными аккаунтами, проверить их отсутствие в результате
- **Особенности:** Удаленные аккаунты добавляются в blacklist для последующих сообщений

### 18. Извлечение участников из пересланных сообщений
- **Описание:** Поиск участников не только в прямых сообщениях, но и в пересланных
- **Источник:** Поля `forwarded_from_id` и `forwarded_from`
- **Тестирование:** Загрузить файл с пересланными сообщениями, проверить участников
- **Особенности:** Игнорируются каналы (по паттерну "channel" в ID, регистронезависимо)

### 19. Форматирование имен файлов
- **Описание:** Автоматическое формирование имен файлов результатов с датой
- **Формат для отдельных чатов:** `{safe_chat_name}_{YYYYMMDD_HHMMSS}.xlsx` (например: `Python_Chat_20251212_143025.xlsx`)
- **Формат для объединенных:** `combined-export-{YYYYMMDD_HHMMSS}.xlsx` (например: `combined-export-20251212_143025.xlsx`)
- **Тестирование:** Загрузить файлы, проверить имена полученных Excel файлов
- **Особенности:** Безопасные имена файлов (sanitization через secure_filename), пробелы заменяются на подчеркивания

### 20. Интеграция с Telegram Bot API
- **Описание:** Полная интеграция с Telegram Bot API для отправки сообщений и файлов
- **Функции:** Отправка документов, текстовых сообщений, inline клавиатур
- **Тестирование:** Проверить все типы сообщений от бота (текст, Excel, клавиатуры)
- **Особенности:** Обработка ошибок API, таймауты 30 секунд, parse_mode Markdown для текста

### 21. Команды бота
- **Описание:** Обработка команд `/start` и `/help`
- **Функции:** Приветствие, инструкции, кнопка открытия WebApp, предупреждение о странице Tuna
- **Тестирование:** Отправить команды боту, проверить ответы и кнопки
- **Особенности:** Предупреждение о странице Tuna при первом открытии, кнопка "Помощь" в inline клавиатуре

### 22. Docker контейнеризация
- **Описание:** Запуск бота и веб-сервера в Docker контейнерах
- **Сервисы:** bot, web, tuna (опционально)
- **Тестирование:** Запустить `docker-compose up`, проверить работу всех сервисов
- **Особенности:** Автоматический перезапуск, логирование, volumes для данных, сеть app_network

### 23. Логирование
- **Описание:** Детальное логирование всех операций
- **Уровни:** INFO, ERROR, DEBUG
- **Тестирование:** Проверить логи через `docker-compose logs`
- **Особенности:** Логирование загрузок, обработки, отправки, ошибок, ротация логов (10MB, 3 файла)

### 24. Ограничение размера файлов
- **Описание:** Защита от загрузки слишком больших файлов
- **Лимит:** 2 ГБ на файл
- **Тестирование:** Попытаться загрузить файл >2 ГБ, проверить ошибку
- **Особенности:** Проверка на клиенте и сервере, настройка MAX_CONTENT_LENGTH в Flask

### 25. Ограничение количества файлов
- **Описание:** Ограничение количества файлов за одну загрузку
- **Лимит:** 10 файлов максимум
- **Тестирование:** Попытаться загрузить 11+ файлов, проверить ограничение
- **Особенности:** Валидация на клиенте и сервере

### 26. Сборка файлов из чанков
- **Описание:** Автоматическая сборка целого файла из загруженных чанков
- **Процесс:** После загрузки всех чанков вызывается `/api/complete-upload`, который собирает файл
- **Тестирование:** Загрузить большой файл, проверить корректную сборку
- **Особенности:** Сохранение метаданных при первом чанке, проверка целостности, удаление чанков после сборки

### 27. Отображение прогресса загрузки
- **Описание:** Визуальное отображение прогресса загрузки файлов
- **Элементы:** Общий прогресс-бар, прогресс по каждому файлу, статус файлов (⏳/✅)
- **Тестирование:** Загрузить несколько файлов, проверить отображение прогресса
- **Особенности:** Обновление в реальном времени, отображение загруженных байт и процентов

### 28. Обработка таймаутов
- **Описание:** Настройка таймаутов для длительных операций
- **Настройки:** 5 минут на чанк, 30 минут на обработку файлов, 1800 секунд для Gunicorn
- **Тестирование:** Загрузить очень большой файл, проверить отсутствие таймаутов
- **Особенности:** Разные таймауты для разных операций, retry при таймаутах

### 29. Безопасность файлов
- **Описание:** Использование secure_filename для безопасных имен файлов
- **Защита:** Предотвращение path traversal атак, sanitization специальных символов
- **Тестирование:** Попытаться загрузить файл с опасным именем, проверить sanitization
- **Особенности:** Замена пробелов на подчеркивания, удаление опасных символов

### 30. Асинхронная обработка
- **Описание:** Асинхронная обработка запросов для лучшей производительности
- **Реализация:** Gunicorn с 2 воркерами для веб-сервера, aiogram для бота
- **Тестирование:** Загрузить несколько файлов одновременно, проверить параллельную обработку
- **Особенности:** Настройки Gunicorn: sync workers, увеличенные лимиты запросов

### 31. Отправка кнопок после обработки
- **Описание:** Автоматическая отправка кнопок для повторной загрузки после завершения обработки
- **Кнопки:** "Загрузить и обработать" (WebApp) и "Помощь"
- **Тестирование:** Загрузить файл, дождаться результата, проверить появление кнопок через 2 секунды
- **Особенности:** Отправка только если BACKEND_URL настроен, задержка 2 секунды перед отправкой

### 32. Прямая загрузка файлов в бот
- **Описание:** Альтернативный способ загрузки файлов напрямую в чат с ботом
- **Лимит:** 20 МБ (ограничение Telegram Bot API)
- **Тестирование:** Отправить JSON файл <20 МБ напрямую боту, проверить обработку
- **Особенности:** Работает без настройки WebApp, но с ограничением размера
