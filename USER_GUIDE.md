# Руководство пользователя

## Как использовать бота для извлечения участников чата

### Шаг 1: Экспорт истории чата из Telegram

1. Откройте **Telegram Desktop** на компьютере
2. Откройте нужный чат
3. Нажмите на три точки (⋮) в правом верхнем углу
4. Выберите **"Экспорт истории чата"**
5. В настройках экспорта:
   - **Формат:** выберите **JSON** (обязательно!)
   - Снимите галочки с "Фотографии", "Видео" и других медиафайлов (чтобы уменьшить размер файла)
6. Нажмите **"Экспорт"**
7. Дождитесь завершения экспорта
8. Сохраните полученный файл `result.json` (или несколько файлов, если история большая)

### Шаг 2: Загрузка файлов в бота

1. Откройте бота в Telegram
2. Нажмите команду `/start` или кнопку **"📂 Загрузить файлы"**
3. В открывшемся окне:
   - Нажмите на область загрузки или перетащите файлы
   - Выберите JSON файлы экспорта (максимум 10 файлов)
   - Проверьте список выбранных файлов
4. Нажмите **"🚀 Загрузить и обработать"**
5. Дождитесь обработки (может занять некоторое время для больших файлов)

### Шаг 3: Получение результата

Результат зависит от количества участников:

#### Если участников меньше 50:
- Бот отправит текстовый список прямо в чат
- Список содержит:
  - Участников чата (кто писал сообщения)
  - Упоминания (@username из текста сообщений)
  - Каналы (если были пересланные сообщения)

#### Если участников 51 и больше:
- Бот отправит Excel файл (.xlsx)
- Файл содержит три листа:
  - **Участники** - список участников чата
  - **Упоминания** - упомянутые пользователи
  - **Каналы** - каналы из пересланных сообщений

### Формат Excel файла

Каждый лист содержит следующие колонки:

| Колонка | Описание |
|---------|----------|
| Дата экспорта | Дата и время создания файла |
| Username | @username (только для упоминаний, для участников - N/A) |
| Имя и фамилия | Имя из профиля Telegram |
| Описание | N/A (недоступно в экспорте) |
| Дата регистрации | N/A (недоступно в экспорте) |
| Наличие канала | N/A (недоступно в экспорте) |

**Важно:** В экспорте Telegram доступна ограниченная информация. Username доступен только для упоминаний (@username в тексте), для участников чата доступен только их ID и имя.

### Обработка нескольких файлов

Если вы загрузили несколько файлов:

- **Файлы одного чата** (с одинаковым названием, типом и ID) автоматически объединяются
- **Файлы разных чатов** обрабатываются отдельно
- Для каждого чата вы получите отдельный результат

### Ограничения

- **Формат файлов:** только JSON
- **Количество файлов:** максимум 10 за раз
- **Размер файла:** до 2 ГБ каждый
- **Кодировка:** UTF-8

### Что извлекается

✅ **Извлекается:**
- Участники чата (кто писал сообщения)
- Упоминания @username из текста
- Каналы из пересланных сообщений

❌ **Не извлекается:**
- Удаленные аккаунты
- Дубли (один пользователь = одна запись)
- Пользователи, которые не писали в чате

### Часто задаваемые вопросы

**Q: Почему для участников нет username?**  
A: В экспорте Telegram username недоступен. Доступен только ID пользователя и имя. Username доступен только для упоминаний (@username в тексте сообщений).

**Q: Можно ли загрузить HTML экспорт?**  
A: Нет, бот работает только с JSON форматом. При экспорте выберите формат JSON.

**Q: Что делать, если файл слишком большой?**  
A: При экспорте снимите галочки с медиафайлов (фото, видео). Это значительно уменьшит размер файла.

**Q: Сохраняются ли мои данные на сервере?**  
A: Нет, файлы обрабатываются "на лету" и сразу удаляются после обработки. Данные не сохраняются.

**Q: Как обрабатываются файлы одного чата, разбитые на части?**  
A: Если вы загрузили несколько файлов с одинаковым названием, типом и ID чата, они автоматически объединяются в один результат.

### Поддержка

Если возникли проблемы:
1. Проверьте, что файл имеет расширение .json
2. Убедитесь, что это экспорт из Telegram (должен содержать поле "messages")
3. Проверьте размер файла (максимум 2 ГБ)
4. Попробуйте экспортировать заново без медиафайлов
