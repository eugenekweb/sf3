# Настройка WebApp для Telegram бота

## Проблема

Telegram Web Apps **требуют HTTPS** для безопасности. Это обязательное требование, которое нельзя обойти.

## Решения

### Вариант 1: Прямая загрузка файлов (работает сразу)

Бот теперь поддерживает загрузку файлов **напрямую в чат**:

1. Отправьте команду `/start`
2. Отправьте JSON файл напрямую в чат
3. Бот обработает файл (лимит 20 МБ)

**Плюсы:**
- ✅ Работает сразу, без настройки
- ✅ Не требует HTTPS
- ✅ Просто для пользователя

**Минусы:**
- ❌ Лимит 20 МБ на файл (ограничение Telegram API)
- ❌ По одному файлу за раз

### Вариант 2: WebApp с туннелем (для разработки)

Для файлов > 20 МБ используйте туннели:

#### Использование ngrok:

1. Установите ngrok: https://ngrok.com/download

2. Запустите туннель:
```bash
ngrok http 5000
```

3. Скопируйте HTTPS URL (например: `https://xxxx-xx-xx-xx-xx.ngrok-free.app`)

4. Обновите `.env`:
```bash
BACKEND_URL=https://xxxx-xx-xx-xx-xx.ngrok-free.app
```

5. Перезапустите бота:
```bash
docker-compose restart bot
```

#### Использование Cloudflare Tunnel (бесплатно):

1. Установите cloudflared: https://developers.cloudflare.com/cloudflare-one/connections/connect-apps/install-and-setup/installation/

2. Запустите туннель:
```bash
cloudflared tunnel --url http://localhost:5000
```

3. Используйте полученный URL в `.env`

#### Использование localtunnel (бесплатно):

1. Установите:
```bash
npm install -g localtunnel
```

2. Запустите:
```bash
lt --port 5000
```

3. Используйте полученный URL в `.env`

### Вариант 3: Продакшен (реальный домен)

Для продакшена используйте реальный домен с HTTPS:

1. Настройте домен (например, через Cloudflare, Let's Encrypt)
2. Укажите в `.env`:
```bash
BACKEND_URL=https://your-domain.com
```

## Текущая конфигурация

Бот автоматически определяет, доступен ли WebApp:

- Если `BACKEND_URL` начинается с `https://` → показывается кнопка WebApp
- Если `BACKEND_URL` начинается с `http://localhost` → показывается кнопка WebApp (для разработки)
- Если `BACKEND_URL` содержит `ngrok` или `localtunnel` → показывается кнопка WebApp
- Иначе → только прямая загрузка файлов

## Рекомендация

**Для начала:** используйте вариант 1 (прямая загрузка) - работает сразу.

**Для больших файлов:** настройте ngrok или другой туннель (вариант 2).

**Для продакшена:** используйте реальный домен с HTTPS (вариант 3).
